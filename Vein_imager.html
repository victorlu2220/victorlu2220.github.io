Near Infrared Vein Imager

View Source on GitHub

Abstract: This project presents an FPGA-based infrared vein imaging system implemented entirely in VHDL. The system captures near-infrared images of subcutaneous veins and performs real-time image processing on an FPGA to enhance vein visibility. The design focuses on efficient, low-latency hardware pipelines for image acquisition, processing, and display.

Figure I. A video of the final result: veins are highlighted on the back of the hand.

Software Workflow

The camera captures videos in grayscale. CLAHE algorithm is applied first to enhance the contrast of the recorded video, followed by Gaussian smoothing to remove noises. Then derivatives are calculated along the rows and columns to compute the elements of the Hessian matrix H_rr, H_cc, and H_rc. These second-order derivatives (curvatures) are then combined using a quantized square-root approximation (for computation efficiency) to determine the final Hessian response, effectively highlighting structural features such as ridges or vessels within the image. A Python script is written for functionality examination before the implementation in VHDL.


VHDL Development Process

The VHDL implementation is comprised of multiple modules, all of the read and write steps from and to RAMs are synchronous:

  • Camera control and communication with VGA: The Control module initializes the OV7670 sensor via an I2C state machine, configuring internal registers. The VGA module captures the resulting video stream, using sync signals to generate X/Y coordinates and valid pixel data for a 128x128 resolution output.
  • CLAHE mapping and output: The CLAHE mapping module generates the local histogram and produces an LUT, which is used by the output module to determine how the original pixel values should be mapped to the new, contrast enhanced pixel values. A top controller module is written to decompose the original 128x128 images into 32x32 patches and process them sequentially to build the unique lookup tables for each region.
  • Convolution: The convolution modules take convolutions along the rows and columns by taking the summation of the 5 nearest pixels, averaging out noises.
  • Gradient and Output: Gradient modules are used to compute the horizontal and vertical gradients of the convoluted image, these effectively detect edges. Following the first order gradient is the second-order gradient, which is used to detect curvatures, a critical feature of the vessels. The Hessian output module solves for the Hessian matrix's principal eigenvalue to find principal curvatures for each pixel. It combines the pre-computed derivatives, uses an LUT to approximate the square root of the discriminant, and outputs a magnitude indicating the likelihood of a pixel being part of a vessel.

Prior to system-level integration, each module undergoes functional verification via a testbench. This process involves using Python to convert an input image into a text-based pixel array, which serves as the simulation input. The testbench processes this data and generates an output file. Finally, the VHDL output is validated against the outputs from golden.py to quantify any discrepancies.


Hardware Setup

The major hardwares used in this project include: a Cmod A7-35T, a camera module, an infrared light emitter and an IR Filter. The microcontroller is used as a 3.3V power supply.
