Near Infrared Vein Imager

View Source on GitHub

Abstract: This project presents an FPGA-based infrared vein imaging system implemented entirely in VHDL. The system captures near-infrared images of subcutaneous veins and performs real-time image processing on an FPGA to enhance vein visibility. The design focuses on efficient, low-latency hardware pipelines for image acquisition, processing, and display.

Figure I. A video of the final result: veins are highlighted on the back of the hand.

Software Workflow

The pipeline turns a raw grayscale frame into a vein-highlighted image in four steps:

  1. Contrast enhancement: CLAHE boosts local contrast, followed by Gaussian smoothing to remove noise.
  2. Curvature detection: row/column derivatives build the Hessian matrix (H_rr, H_cc, H_rc) at every pixel.
  3. Vessel response: those curvatures are combined via a quantized square-root approximation (cheap to compute in hardware) into a single score that lights up ridge-like structures such as veins.
  4. Verification: a Python "golden model" implements the same math first, so the VHDL output can later be checked against it.

VHDL Development Process

The design is split into four synchronous modules, each reading and writing RAM on the clock:

  • Camera control and VGA: one module initializes the OV7670 camera sensor over I2C; another reads its video stream and times out a clean 128×128 pixel grid from the sync signals.
  • CLAHE mapping: the 128×128 frame is split into 32×32 patches; each patch gets its own local histogram and lookup table, which then remaps every pixel to its contrast-enhanced value.
  • Convolution: each pixel is averaged with its 5 nearest neighbors along rows and columns to suppress noise before edge detection.
  • Gradient & Hessian output: first-order gradients find edges; second-order gradients feed the Hessian matrix. A final module solves for its principal eigenvalue (approximating the square root via a lookup table) to score how vessel-like each pixel is.

Each module is verified on its own before integration: a Python script converts a test image into a pixel array, the VHDL testbench processes it, and the result is diffed against golden.py's output.


Hardware Setup

  • Cmod A7-35T — the Artix-7 FPGA board running the full pipeline; its onboard regulator also supplies 3.3V to the rest of the circuit.
  • OV7670 camera module — captures the raw grayscale video.
  • Infrared emitter — illuminates the hand for subcutaneous contrast.
  • IR-pass filter — blocks visible light so only the IR signal reaches the sensor.
