Real-time Tracking for Medical Suturing

Abstract: Precise needle and thread tracking matters most in minimally invasive surgery, where the margin for error is small. This project tracks both in real time by combining computer vision with sensor fusion, comparing three segmentation architectures—UNet, nnUNet, and Attention-UNet—on the same labeled dataset to find the best fit. The goal: a tracker responsive and reliable enough to plug into robotic surgical tools or AR-based training platforms.

Data Preparation

Dataset: Real-world suturing videos were split into individual frames: about 10,000 for scalpels, but only 410 for thread, since thin thread is much harder to label by hand.

Masking: A custom UI (below) makes labeling the thin threads manageable. Color marks directionality—green for the leading end, blue for the trailing end—which later helps the model infer direction of travel.

Video Formation: A Python tool overlays the labeled masks back onto the original frames, reconstructing a video with the masks applied for visual sanity-checking.

Data Preprocessing: The dataset is formatted with the nnUNet preprocessing tool, which keeps it in one consistent format that all three model architectures can train and evaluate on.

Training and Results

nnUNet came out on top of the three models on this dataset (results below). The main open problem is thread tracking: masks for the thin thread are often discontinuous, which confuses inference about where the thread actually is. A ConvLSTM, which reasons across frames instead of one at a time, could smooth this out. More thread-labeled data, which was the scarcest part of the dataset, would likely help too.
